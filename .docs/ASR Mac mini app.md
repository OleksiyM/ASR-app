
**маленькая и честная**.

Не “ещё один ИИ-комбайн”, а просто:

- висит в меню-баре
- по hotkey или клику слушает
- шлёт аудио в `Whisper Turbo`
- возвращает **чистый текст**
- копирует в буфер / вставляет / сохраняет
- а дальше уже пусть агент, тул или ты сам решаете, что с этим делать

**этому приложению не нужно думать.**
Ему нужно:
- быстро слушать
- хорошо распознавать
- удобно отдавать текст

Именно поэтому идея сильная.

MVP:

- `Menu bar app` для macOS
- global hotkey
- toggle record - для начала и возможно потом push-to-talk 
- индикатор: `listening / uploading / transcribing / done`
- output modes:
  - copy to clipboard
  - paste into current app
  - save to note/file
  - macOS native share
- настройки:
  - Whisper API key - да
  - язык `auto/ru/en` - позже
  - модель и прочиенастройки - json файл в интерфейсе или пока отдельно с заддыми по умолчани.  
  - auto-paste on/off

Почему это хорошо:
- не зависит от OpenClaw
- не зависит от Telegram
- работает в любом контексте
- это уже почти **универсальный голосовой вход в AI-дом**

И да, потом поверх можно наращивать:
- “отправить агенту”
- “сделать задачу”
- “превратить в markdown list”
- “добавить в inbox”
**это уже второй слой, не первый.**

Коротко:
И это как раз тот редкий случай, где маленькое приложение может дать очень много реальной жизни.
